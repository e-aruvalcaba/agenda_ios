# Agenda PWA (Vite + React)

Proyecto base para una PWA offline-first que gestiona citas y ganancias, usando `Dexie` (IndexedDB).

Scripts:

 - `npm install`
 - `npm run dev` — iniciar en modo desarrollo
 - `npm run build` — generar estático
 - `npm run deploy` — publicar en GitHub Pages (requiere configurar `homepage`/repo)

Contenido generado: scaffold con calendario, formularios de citas y pagos, export/import JSON y SW básico.
